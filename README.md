Smart Analytics Tool

Overview

This project is a Smart Analytics Tool built using Streamlit, Pandas, and Plotly. It allows users to upload CSV files and perform basic data analysis and visualization.

Features

- CSV File Upload
- Dataset Preview
- Missing Value Analysis
- Statistical Summary
- Histogram Visualization
- Box Plot Visualization
- Scatter Plot Visualization

Technologies Used

- Python
- Pandas
- Streamlit
- Plotly

Instructions to Run

1. Install required libraries:
   pip install streamlit pandas plotly

2. Open terminal in the project folder.

3. Run the application:
   streamlit run app.py

Output

The tool helps users analyze uploaded datasets and generate visual insights through dynamic charts and statistical summaries.
